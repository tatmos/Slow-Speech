# Slow Speech

ブラウザ上で動作する音声リサンプリングツールです。音声ファイルを読み込み、再生レートを変更しながら波形を確認・編集し、加工後の音声をWAV形式で書き出せます。

## 主な機能

- **音声アップロード**: WAV/MP3 などの音声ファイルを読み込み
- **再生レート調整**: スライダーまたは数値入力で再生速度を変更
- **リサンプリングアルゴリズム選択**:
  - シンプルにリサンプル
  - 音の長さを保つように無音をカット
  - 音量スレッショルドでレート調整
- **波形表示**: 元波形と加工後の波形を別トラックで表示
- **利用範囲の指定**: 元波形上で範囲をドラッグして抽出区間を設定
- **プレビュー再生**: 加工後の音声を再生して確認
- **ファイル保存**: 加工後の音声を WAV で保存

## 使い方

1. `index.html` をブラウザで開きます（ローカルサーバーでも可）。
2. 「波形をアップロード」から音声ファイルを選択します。
3. 元波形の範囲をドラッグして利用範囲を調整します。
4. 再生レートやアルゴリズムを変更し、プレビューで確認します。
5. 「ファイル保存」から加工後の WAV を保存します。

## プロジェクト構成

- `index.html`: 画面レイアウトとUI要素の定義
- `style.css`: UIスタイル
- `app.js`: アプリ全体の初期化・制御
- `uiController.js`: ボタン/スライダー/ドロップ操作などのUI制御
- `audioProcessor.js`: バッファ範囲抽出とWAV書き出し
- `audioPlayer.js`: プレビュー再生と再生状態管理
- `resampleAlgorithms.js`: リサンプリング処理とアルゴリズム切り替え
- `waveformRenderer.js`: 加工後波形の描画
- `originalWaveformViewer.js`: 元波形表示と利用範囲の選択
- `waveformDrawer.js`: 波形描画ユーティリティ
- `timeRuler.js`: 時間目盛り描画
- `levelMeter.js`: レベルメーター表示

## 技術仕様
